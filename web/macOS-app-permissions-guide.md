# macOS 应用权限详解：它们在要什么、能干什么

> 按弹窗顺序整理，覆盖 Agent 类应用（Claude Code / Cursor / ZCode / Trae / GitHub Copilot CLI 等）最常申请的那些权限。
> 给每条结论是 **建议**：拒 / 可 / 看场景，依据是"这个权限被滥用能造成什么最坏后果"。

---

## 1. 文件与文件夹（Files and Folders）

**弹窗长这样**："ZCode 想访问 iCloud Drive / Downloads / Desktop / Documents 等文件夹"
**系统设置位置**：隐私与安全性 → 文件与文件夹

### 它能干什么
- 读那个文件夹里的**所有文件**（包括你拖进去就忘掉的截图、发票、笔记、密钥）
- 修改 / 写入 / 删除该文件夹内的文件（Electron 应用拿到后可以直接写）
- iCloud Drive 这条最危险：里面可能是你**多设备同步**的家底

### 典型滥用场景
| 应用类型 | 最坏情况 |
|---|---|
| AI 编程工具 | 把你仓库里的 `.env` / `secrets.json` / SSH 密钥**上传到它的云端 API** 喂给模型 |
| 笔记 / 同步类 | 全量同步走第三方服务器（非端到端加密） |
| "优化"工具 | 顺手把你 Desktop 里 30GB 的东西塞进它的回收站 |

### 建议
- **AI 类（Cursor/ZCode/Claude Code）给的是工作目录本身，一般够用了**，不需要 Downloads、iCloud 全量授权
- 下载 / 桌面 / 文稿：默认拒绝，确实要再给
- iCloud Drive：**除非是同步类 App，否则一律拒绝**

---

## 2. 完全磁盘访问（Full Disk Access）

**系统设置位置**：隐私与安全性 → 完全磁盘访问
**门槛最高**：需要输入密码，且 macOS 会明确告诉你"这个 App 能看到你电脑里的所有东西"

### 它能干什么
- 绕过 TCC 沙箱，读**整个磁盘**：浏览器历史、钥匙串、邮件、短信、照片、Time Machine 备份
- 读 `/Volumes/` 上的移动硬盘
- 直接执行 `sqlite3` 打开任意 SQLite 文件

### 哪些应用"合理"要
| 应用 | 为什么 |
|---|---|
| 终端 / iTerm / VS Code / Warp | 你需要让它 `ls` 任意目录 |
| 备份工具（Time Machine、Carbon Copy Cloner） | 备份必须全量 |
| 杀毒 / 终端隔离软件（Spike、MalwareBytes） | 扫描全盘 |
| 网络抓包 / Wireshark | 读网络栈需要 |

### 哪些应用"不该"要
- AI 编程助手：**不该要**，给它对应仓库目录的"文件与文件夹"就够
- 任意"AI Agent / 自动化工具"：如果它要全量磁盘访问来"理解你的电脑"，这是**数据收集信号**，强烈拒绝
- 游戏、输入法、表情包插件：不该要

### 建议
**白名单制**：只给终端、备份、杀软。其他全拒。定期清一次这个列表（很多人 1~2 年就攒了 20 个进去忘了）。

---

## 3. 自动化 / 辅助功能（Automation & Accessibility）

**位置**：隐私与安全性 → 自动化 / 辅助功能

### 它能干什么
- **自动化**：控制你其他 App（AppleScript / JXA）—— 读你打开的 Mail、Safari 标签页、日历事件、备忘录
- **辅助功能**：模拟鼠标键盘、读屏幕（OCR 截图）

### 典型滥用场景
- "AI 帮你操作电脑"类应用（Raycast AI / Cursor Agent 桌面版）拿到自动化权限后，**能读取你所有 App 的窗口标题**（= 你最近在干什么的情报）
- 拿到辅助功能 + 屏幕录制 = 完整 RPA，相当于在你电脑里装了一个能 24h 看着你干活的间谍

### 建议
- **只给你明确要"代替你操作"的工具**（Raycast、Shortcuts、JXA 脚本）
- AI 助手类：**拒**——它自己会写脚本，不需要模拟你

---

## 4. 屏幕录制（Screen Recording）

**位置**：隐私与安全性 → 屏幕录制
**特征**：开了以后截图会有"隐私"标记，录制的画面里会出现你正在看的内容

### 它能干什么
- 全量录屏 / 截图 / OCR
- 配合辅助功能 = 完整的"看见你电脑"能力

### 谁该要
- 录屏工具（OBS、CleanShot、Kap）
- 投屏 / 串流（Zoom 录屏、QuickTime 录屏、游戏串流）

### 谁不该要
- AI 编程助手（它要看代码读文件就行，看屏幕是**过度收集**）
- 输入法 / 剪贴板工具：不该要

### 建议
**白名单制**，只给录屏 / 串流工具。AI 类一律拒。

---

## 5. 麦克风

### 它**真的**要干嘛
- 语音输入 / 语音指令 / 语音转写

### 它能干什么
- 持续监听并上传（如果应用代码是恶意的）
- 合法用途：会议纪要工具（Otter、Teams 转录）、语音 AI 助手

### 建议
- 你确实在用语音交互的 AI / 会议工具：**给**
- 其他一切（包括"AI 编程"工具）：**拒**——写代码不需要麦克风

---

## 6. 摄像头

### 它**真的**要干嘛
- 视频通话 / 直播 / 视频会议（Zoom、FaceTime、腾讯会议）
- 扫证件 / 扫码（少数）

### 它**可以**干什么
- 偷拍你
- 配合 face id 解锁设备

### 建议
- 只有视频会议工具该要。AI 类、输入法、笔记类：全拒。

---

## 7. 定位（Location）

### 它**真的**要干嘛
- 地图 / 导航 / 附近推荐 / 天气
- 照片 / 备忘录 自动打地理标（系统自带）

### 它能干什么
- 持续追踪位置 + 时间 = 行踪数据，可被卖给广告主或（恶意时）直接外传
- 配合 Wi-Fi 列表能反推你常去的位置（比 GPS 更细粒度）

### 建议
- 地图 / 打车 / 社交 App：给"使用期间"
- 笔记 / 照片 / 工具类：**默认关**，需要时手动开
- 任何你说不清"为什么它要位置"的 App：拒

---

## 8. 通知（Notifications）

### 它能干什么
- 推送消息（可以带 URL / 深链，点了就跳到它指定的页面）
- 在锁屏上显示任意文字（= 在锁屏上写广告 / 钓鱼文案）

### 建议
- 聊天 / 工作工具给；营销 / 游戏 / 工具类拒（你不需要它弹"快来试试 XX 新功能"）

---

## 9. 日历 / 提醒事项 / 通讯录 / 健康

### 它们能干什么
- **读你的会议时间** → 推断你什么时候在办公室 / 出差 → 配合位置数据画像
- 读通讯录 → 完整社交图谱（最敏感的 PII）
- 健康 App 拿到运动 / 心率 = 完整生理画像

### 建议
- 只有"日程管理 / 会议 / 邮件"类需要日历（如 Spark、Things、Apple 自带）
- 任何 AI 编程 / 笔记 / 工具类要求通讯录 / 日历：**默认拒**

---

## 10. 输入监控 / 键盘事件（Input Monitoring）

**位置**：隐私与安全性 → 输入监控
**特征**：能拦截每个按键、剪贴板操作

### 它能干什么
- **按键记录 = 完整的密码记录器**
- 读剪贴板（你的 SSH key、token、密码都会复制进去）
- 这是**键盘窃贼（keylogger）的标准姿态**

### 哪些应用合理要
| 应用 | 为什么 |
|---|---|
| 自定义快捷键 / 剪贴板管理器（Raycast、AlDente、Maccy） | 需要全局监听按键 / 粘贴 |
| 输入法（搜狗 / 微信输入法） | 捕获你的输入 |
| 远程桌面（ToDesk / 向日葵 / TeamViewer） | 远程键盘 |

### 哪些应用**绝对不该**要
- AI 编程工具：它们应该读的是你的**文件**，不是你的按键
- 浏览器 / 输入法以外的任何"AI 助手"：**看到就要警惕**

### 建议
**白名单制**。如果你看到一个 AI / 营销类 App 在输入监控列表里，**直接删掉**。

---

## 11. 蓝牙 / 个人热点 / 网络

### 它**真的**要干嘛
- 蓝牙：连接外设（键盘、耳机、手柄）
- 网络：正常联网（所有 App 都需要，但 macOS 默认就允许）

### 它能干什么
- 连接你电脑上的蓝牙设备 → 控制你的智能门锁、耳机
- 热点：把流量分给别的设备（企业 VPN 场景）

### 建议
- 蓝牙只给外设工具。其他全拒。
- 热点只有 VPN / 企业 App 给。

---

## 12. 通讯录 / 通话记录

### 它**真的**要干嘛
- 通讯工具（钉钉、企业微信、Telegram）拉联系人建会话
- 通话记录：**合法理由几乎都是伪造**，只有运营商 / 系统自带"电话"App 需要

### 建议
- 通讯工具给"通讯录"，**拒"通话记录"**
- 其他一律拒

---

## 13. 辅助功能之外的"万能钥匙"：Apple 事件 / Automation

前面说过。补一点：在 macOS 13+ 上，Automation 默认**每次触发都弹一次**（可选"始终允许"），这是好事——别点"始终允许"，保持每次确认。

---

## 总结：一张速查表

| 权限 | 谁该要 | AI 编程 / Agent 工具 | 默认 |
|---|---|---|---|
| 文件与文件夹 | 编辑器 / 工作流工具 | 给对应工作目录 | 给（限目录） |
| 完全磁盘访问 | 终端 / 备份 / 杀软 | **不要** | 白名单 |
| 自动化 | RPA / Raycast | **不要** | 每次确认 |
| 辅助功能 | RPA / 无障碍 | **不要** | 白名单 |
| 屏幕录制 | 录屏 / 串流 | **不要** | 白名单 |
| 麦克风 | 语音 AI / 会议 | **不要** | 拒 |
| 摄像头 | 视频会议 | **不要** | 拒 |
| 定位 | 地图 / 导航 / 天气 | **不要** | 拒 |
| 通知 | 聊天 / 工作 | 可选 | 看工具 |
| 日历 / 提醒 / 通讯录 | 日程 / 通讯工具 | **不要** | 拒 |
| 输入监控 | 快捷键 / 输入法 | **不要** | 白名单 |
| 蓝牙 | 外设工具 | **不要** | 拒 |

**一句话原则**：
1. 每个权限对应一个**具体的能力**（能看见 / 能操作 / 能上传），问自己"这个能力**真的**对这个 App 的功能是必须的吗？"
2. 任何 AI / Agent 类应用申请超出"读代码"之外的权限（麦克风、摄像头、定位、输入监控、完全磁盘、辅助功能），**默认是数据收集 / 过度授权信号**，先拒，确认可替代再给。
3. 给过的权限**每季度清一次**：系统设置 → 隐私与安全性，每个列表扫一遍，没理由的删。

## 附：快速查看某 App 当前拿到了哪些权限

```bash
# 命令行查 TCC 数据库（需要密码）
sudo sqlite3 "/Library/Application Support/com.apple.TCC/TCC.db" \
  "SELECT service, client, auth_value, auth_reason \
   FROM access WHERE client LIKE '%zcode%';"

# 查用户级
sqlite3 "$HOME/Library/Application Support/com.apple.TCC/TCC.db" \
  "SELECT service, client, auth_value FROM access WHERE client LIKE '%zcode%';"
```

`auth_value`: 0=拒绝, 2=允许, 3=有限允许（如"仅使用期间"）。
